# Small Projects Practice 🐍

A collection of small beginner-friendly Python programs I built to practice core programming fundamentals like loops, functions, user input, and data handling.

## Projects

| Project | Description | Concepts Practiced |
|---------|-------------|--------------------|
| [Bill Split Calculator](./A%20Bill%20Split%20Calculator) | Splits a total bill (with optional tip) evenly among people | `input()`, type conversion, arithmetic |
| [Contact Book](./A%20Contact%20Book) | Add, search, and view contacts | Dictionaries, lists, menus, `while` loops |
| [Daily Expense Tracker](./A%20Daily%20Expense%20Tracker) | Records daily expenses and shows the total spent | Lists, loops, functions |
| [Factorial](./A%20Factorial) | Calculates the factorial of a number | Loops / recursion |
| [Flat Asterisk Pyramid](./Build%20a%20Flat%20asterix%20pyramid) | Prints a pyramid pattern using `*` | Nested loops, string multiplication |

## How to Run
1. Download or clone this repo
2. Open any project folder
3. Run the Python file: `python filename.py`

## What I Learned
- Taking and validating user input
- Using loops and conditionals
- Writing reusable functions
- Working with lists and dictionaries
- Printing patterns with nested loops
